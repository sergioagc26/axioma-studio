# La Bodega · «Etiqueta por etiqueta» (guía animada para Laura)

Pieza vertical 1080×1920, 40 s, 30 fps. Tipografía cinética a 120 BPM.

```bash
node labodega-etiquetas-laura/scripts/audio.mjs
```

```bash
npx remotion render labodega-etiquetas-laura/src/index.ts LaBodegaEtiquetas labodega-etiquetas-laura/Renders/labodega-etiquetas-laura.mp4 --public-dir=labodega-etiquetas-laura/public
```

La única pantalla que aparece es una captura real de la página de ingreso. El resto son los nombres exactos de los botones del panel, sin pantallas dibujadas.
