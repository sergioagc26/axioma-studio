# Conceptos

Un solo concepto bien ejecutado. El precio asequible o la promesa es parte de la historia.

## Ya probados (no repetir para la misma persona sin que lo pida)

| Concepto | Idea | Sirve para |
|---|---|---|
| Tipografía cinética | palabras y precios golpean al ritmo (808/trap) | comida, ofertas |
| Réplica de celular | la web en un teléfono; los precios se salen de la pantalla y se simula el pedido | pedidos en línea |
| Marcador split-flap | un tablero que "gasta" un presupuesto con precios reales | productos económicos |
| Portal zoom | la cámara se mete dentro de cada botón del flujo real de compra | explicar cómo pedir |
| Etiquetas y sellos | foto grande, ingredientes señalados con líneas y sello de precio | antojo, carta |
| Dial 360° | un diagnóstico en cuadrantes: pregunta y resultado | servicios, consultoría |
| Papel recortado | stop-motion, hojas rasgadas, letras de recorte | marca personal, agencias |
| Mapa de metro | líneas = áreas de un servicio que confluyen | procesos y sistemas |
| Persiana y banda | una persiana se abre por momento; los productos desfilan en cajas | tiendas, temporada |

## Por explorar

Cómic pop-art · glitch/VHS · interfaz de videojuego original · recibo o ticket que se imprime · vitrina o máquina expendedora · receta que se arma por capas · calendario o cuenta regresiva real · mapa del barrio con recorrido del domicilio.

## Ritmo

Cambia de escenario cada ~3 s con una imagen distinta por idea. Mover la cámara por el mismo tablero aburre. Mantén una guía visible (barra de pasos, marcador) para que no se pierdan. El texto se queda 2–3 s.
