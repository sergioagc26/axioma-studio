# promo-motion · skill de Axioma Studio

Convierte un enlace o una marca en un video promocional animado con Remotion.

## Cómo se usa
Viene incluida en Axioma Studio. Con el plugin activado, pide: «hazme una promo animada de <enlace>».

Sin Axioma: copia esta carpeta en `~/.claude/skills/`.

## Contenido
- `SKILL.md`: el proceso paso a paso.
- `references/`: plantilla de pedido, conceptos, audio, voz en off, técnica y lecciones.
- `plantilla/`: proyecto Remotion de ejemplo (10 s) con generador de audio, vistas previas y verificación.

Las skills oficiales de Remotion no vienen incluidas: la skill ofrece instalarlas la primera vez.
