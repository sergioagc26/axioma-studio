Instala Axioma Studio en tu computador

Axioma Studio edita reels y videos verticales con IA. Corta, subtitula, pone voz y música, y exporta listo para Instagram. Todo corre en tu propio computador.

Windows 10/11 o macOS 13+ Primera vez: 20 a 40 min Necesitas: cuenta de GitHub (gratis)

1. ¿Tu computador sirve?

La app mide tu computador al abrirla y se configura sola. Con menos del mínimo funciona, pero lenta y sin algunas funciones de IA.

MínimoRecomendado
Memoria RAM8 GB16 GB o más
Procesador4 núcleos8 núcleos, o Mac con chip M1 o superior
Tarjeta de videoCualquieraMac con chip Apple, o NVIDIA de 8 GB
Disco libre20 GB50 GB
InternetSolo para instalar (baja unos 3 GB, u 11 GB con la IA local) y para actualizar.

2. Pide acceso (una sola vez)

La app vive en un proyecto privado de GitHub. Para bajarla, el dueño te tiene que invitar.

  1. Crea tu cuenta de GitHub

    Entra a github.com/signup y crea una cuenta gratis. Si ya tienes una, usa esa.

  2. Envía tu nombre de usuario

    Mándale a quien te compartió este manual tu nombre de usuario de GitHub (no tu contraseña). Con eso te invita al proyecto.

  3. Acepta la invitación

    Te llega un correo de GitHub: «View invitation» → «Accept invitation». Sin este paso el instalador no puede bajar la app.

3. Instala

  1. Baja el instalador

    Abre el link que te compartieron y descarga Axioma Studio para Windows.zip (pesa unos KB: el resto lo baja solo).

  2. Descomprímelo

    Clic derecho sobre el .zip → Extraer todo → Extraer.

  3. Abre el instalador

    Doble clic en «Instalar Axioma Studio.bat». Si aparece «Windows protegió su PC», pulsa Más información → Ejecutar de todas formas.

  4. Entra a GitHub

    Cuando salga la ventana de GitHub, pulsa «Sign in with your browser» y entra con tu cuenta (la que aceptó la invitación). Solo la primera vez.

  5. Responde dos preguntas

    Si pregunta por traer proyectos desde iCloud, responde N (eso es solo para el dueño). Si pregunta por la IA local, responde S si tu computador tiene 16 GB de RAM o más; si no, N.

  6. Espera

    Instala solo Node, FFmpeg, la transcripción y la IA. No cierres la ventana. Al terminar aparece «Axioma Studio» en el Escritorio.

Si dice «Falta winget», instala App Installer desde Microsoft Store y abre el instalador otra vez.

  1. Instala GitHub Desktop

    Baja GitHub Desktop (gratis), ábrelo y entra con tu cuenta de GitHub (la que aceptó la invitación).

  2. Baja la app

    En GitHub Desktop: File → Clone repository → pestaña URL, pega sergioagc26/axioma-studio. En Local path elige tu carpeta de usuario y pulsa Clone.

  3. Abre el instalador

    En Finder, entra a la carpeta axioma-studio. La primera vez: clic derecho sobre «Instalar Axioma Studio.command» → Abrir → Abrir (así macOS lo deja correr).

  4. Escribe la contraseña del Mac

    Instala las herramientas de Apple y Homebrew, que piden la contraseña de tu Mac. Al escribirla no se ve nada: es normal, escríbela y pulsa Enter.

  5. Responde y espera

    Si pregunta por la IA local, responde s si tu Mac tiene 16 GB o más. Al terminar aparece «Axioma Studio» en el Escritorio y la app se abre sola.

4. Primer uso

  1. Ábrela

    Doble clic en «Axioma Studio» del Escritorio. Se abre en tu navegador, en localhost:4747. Es tu computador, no una página de internet.

  2. Optimízala para tu computador

    Proyectos → Ajustes → Configuración → Optimizar para este computador. Elige la IA, la voz y la velocidad de exportación que le caben.

  3. Pon tus claves (opcional)

    En Proyectos → Claves pegas las tuyas: ElevenLabs (voces más naturales), Pixabay y Freesound (música y videos libres). Cada botón «Sacar la clave» abre la página donde está. Sin claves la app funciona con la voz y la música locales.

  4. Haz tu primer video

    En Nuevo video elige Hablando a cámara o Sin voz, arrastra tu video y sigue el brief.

Si algo falla

«No se pudo bajar la app»

Casi siempre falta aceptar la invitación de GitHub (paso 2.3) o entraste con otra cuenta. Acepta la invitación, abre el instalador otra vez y entra con la cuenta invitada.

Windows no deja abrir el .bat

Pulsa Más información → Ejecutar de todas formas. Si tu antivirus lo bloquea, permite el archivo una vez.

macOS dice «desarrollador no identificado»

Clic derecho sobre el archivo → Abrir → Abrir. Solo hace falta la primera vez.

Se queda mucho rato en «IA local»

Está bajando entre 5 y 11 GB. Déjalo terminar. Si tu internet es lento, puedes responder que no y bajarla después desde Configuración.

La exportación se corta o el computador se pone lento

En Configuración pulsa Optimizar para este computador: baja la cantidad de procesos y el tamaño de la IA. Cierra otras apps pesadas mientras exportas.

Otro error

El detalle queda en workspace/instalacion.log. Envía ese archivo, o una foto de la ventana del error, a quien te compartió la app.

Uso en empresas. La app exporta con Remotion, que es gratis para personas y empresas de hasta 3 empleados. Una empresa más grande necesita su propia licencia de Remotion (remotion.dev/license).
